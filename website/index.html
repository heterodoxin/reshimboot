Info:
reshimboot boots a full, modern Debian desktop on a dedede Chromebook from a Chrome OS RMA shim. It doesn't touch the firmware and works on enterprise enrolled devices.

It is a fork of shimboot that focuses on one board, so everything can be tuned for it: Debian 13, PipeWire, a bootloader that repairs the filesystem before booting, fixes for audio, Wi-Fi, iptables and random reboots, and a build that needs about 97% less shim download.

Supported Devices:
Only Chromebooks whose board is "dedede" (Intel Jasper Lake: Celeron N4500, N5100, Pentium N6000). Look up your model on cros.download to find its board. For other boards, use the original shimboot.

Explanation:
Chrome OS RMA shims are bootable disk images meant for diagnostics, and they boot even on enterprise enrolled devices. Their kernel is signed, but due to a security flaw their root filesystem is not verified, so it can be replaced with anything.

reshimboot replaces it with a small bootloader. It shows a menu, checks the Debian filesystem, and then does a pivot_root into Debian. The Chrome OS kernel rejects a normal systemd, so a patched systemd is used. Kernel modules and firmware come from the shim and the recovery image.

The shim kernel for dedede is Linux 5.4 and cannot be replaced (it has no kexec), so reshimboot adapts Debian to it.

Build Instructions:
1. Clone the repository and cd into it.
2. Run `sudo ./build_complete.sh` (or `sudo ./build_docker.sh` if you are not on Debian or Ubuntu).
3. The image is written to data/shimboot_dedede.bin

Booting the Image:
1. Flash the image to a USB drive or SD card with the Chromebook Recovery Utility, balenaEtcher, or dd.
2. Enable developer mode. If the Chromebook is enrolled, follow the instructions on the sh1mmer website.
3. Plug in the drive and enter recovery mode. The reshimboot bootloader starts Debian after a short countdown.
4. Log in as user / user. A welcome screen asks you to choose a new password.

AI-Assisted Development:
This fork was developed with the help of an AI coding assistant (Claude, by Anthropic). Changes were checked by building real images against the dedede shim and recovery image, and by testing the bootloader with the shim's own busybox. Not everything has been confirmed on real hardware yet, so please report what works on your Chromebook.
